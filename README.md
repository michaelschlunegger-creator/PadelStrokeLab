## Build and test

Use Xcode 27.0 with iOS and watchOS 27 SDKs. Open `PadelStrokeLab.xcodeproj`; schemes are `PadelStrokeLab` and `PadelStrokeLab Watch App`. Both apps use local `Packages/PadelCore` (metadata and recording storage) and `Packages/PadelDesign` (SwiftUI presentation), without third-party dependencies. Xcode 27 opens simulated devices in Device Hub.

For command-line operations set `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`. Store DerivedData and result bundles outside the source and synced Drive folders. The full commands and limits are in [Testing](docs/TESTING.md).

The baseline Watch requests motion access and HealthKit workout sharing to support explicit recording. It requests no Health read types and saves no workout summary; watchOS may nevertheless record workout HR/activity in Health. The first tester visibly limits each recording to120 active seconds. Ten manually selected intended shot types are implemented in the reviewed logger; no automatic counts or scoring follows. Last verified physical installation/launch is build4; current local branding/source is newer and has not replaced it. Current tests, proposed richer statistics, guest-mode investigation and remaining physical/CI/review gates are recorded above and in GATE_CARD.
