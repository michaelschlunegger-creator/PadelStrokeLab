# O7 HR-only authority transition prerequisite review
22 October2026. Independent Sol read-only audit of frozen O4/O5 APIs; this is a risk-review input to the later Astra ownership plan, not implementation or source release. O7 remains held.

Current O5 receive(.mutate) revokes capture/clears preparation for every mutation, including an optional-HR-only change, and the model shuts down the per-set workout. validateAdmission invokes binding.validateCurrentAuthority, which correctly requires byte-exact admission authority; resuming an old context against any later HR revision fails. This behavior must be deliberately reconciled with the approved O7 requirement to stop/exclude HR without rewriting an existing raw set or inventing motion consent.

No Core visibility expansion is inherently required. Public mutation kind, resolve(from:), consentDecision(for:), checked channel.sequence result and owner identity fields provide an exact HR-only chain. O7 must retain original raw admission authority/context separately and prove unchanged owner/epochs/policy/motion grant/withdrawal barrier across every contiguous checked HR-only transition. Pending/fresh Starts remain fully exact and fenced. Unknown, failed, skipped or non-HR transitions fail closed. Do not expose private binding authority bytes or treat canonical context as current permission.

OwnerPreparationObservation.validate also requires acceptedCurrent/acceptedNext to match CURRENT authority digest/revision exactly. After HR revision, clear stale preparation presentation and next-admission identity; retaining an old accepted preparation would make status unencodable. Old active raw-context identity belongs only in the separately checked runtime motion-carry proof. Never forge accepted preparation/context or weaken wire validation to make status pass.

Separate immutable practice/native-session identity from per-set admission/attempt identity. Delayed running/paused events from a prior set must never authorize a new one. Same-practice next admission requires old ingress sealed, source stopped, actual writer drain, fresh local confirmation/context and the same live authorized native practice. Replacement practice still waits for observed native ended plus HR/source/writer closure. Concrete O7 states, event sequencing, pause/resume and race tests need Astra plan and independent review before source edits. The conditionally justified eighth coordinator file stays within original2,300-line cap; any extra prerequisite is split before implementation.

The audit separately found the actual O5 retired-reply codec blocker, documented in [its own bounded correction](261022_Owner_First_O5_Retirement_Blocker_v1.0.md). That defect must be fixed/reverified now and cannot be hidden in O7.
