## First dry run, one action at a time

1. Open Practice on the physical Watch after both apps are confirmed installed/launched on the correct build. Choose Backhand volley as intended shot type. Expected: native choice is visible; this is a manual label for the set, not a detected stroke. Record one type per short set.
2. Select the actual playing/racket arm and handedness; wear the Watch on that arm with the correct system wrist/crown setting. Confirm Watch on this arm. Expected: confirmation is fresh and actual configuration matches. End other workouts before starting this app's capture.
3. Tap Start recording and answer system Motion/Health prompts. Expected: Starting becomes Recording only when both real streams have arrived, with increasing accepted counts. Shot choice stays fixed. No saved Apple Health workout summary is requested; system activity metrics may still change.
4. Make one controlled backhand-volley-style AIR swing, then tap Stop and save after movement. Do not interact with the screen during movement. Expected: actual capture/workout resources stop and retained data is saved/verified or an explicit interrupted/failure state appears. The limit is120 active seconds excluding pauses; sensor-tail completeness remains unknown.
5. Open Sessions on iPhone; use Send to iPhone on the retained Watch recording if necessary. Expected: exactly one matching recording receives a verified application receipt; OS transfer completion/queued status alone is insufficient. Record ID, raw counts, coverage/rates/gaps and any warning on both devices.
6. Open the phone recording and review Intended shot type, raw drill and stored protocol. Expected: Backhand volley, `backhandVolley`, `owner-manual-training-logger-1`, and matching recording identity. Capture actual displayed values. No automatic impact timing or contact score should appear.
7. Add an Air swing attempt with actual confidence, owner provenance and an evidence note. Expected: it is not a clean/mishit contact; unmatched attempt timing remains unmatched/uncertain for analysis. Edit the note once and verify revision history with raw data unchanged.
8. Prepare export and Share recording bundle to an explicit owner-controlled destination. Expected: original signals, metadata/type/protocol, timeline, all label revisions and integrity information. Coordinator reads the export back and verifies ID, type/protocol, both stream counts, raw metadata/chunk bytes and label revisions before collecting court contacts. No automatic public/Drive upload.
9. Prepare new set on Watch and select a different type. Expected: fresh placement confirmation is required, new type is editable only before Start, prior saved recording/review/export retains Backhand volley and original protocol. Relaunch should preserve valid shot choice but never placement confirmation.

## Subsequent workflow checks

Perform each independently after the dry-run/export pass: pause/resume with fresh counts and explicit gaps; wrist lowered/app background; phone absent during capture then later verified transfer; retransmission without duplication; permission denial then Settings recovery; interrupted capture/relaunch with honest retained-data status; explicit local-copy deletion and cancellation; limits and battery observations. Preserve failed observations. Do not combine unknowns into one test.

Deletion affects only the explicitly selected device copy and managed artifacts. Other-device copies and independent exports remain. A phone tombstone prevents automatic resurrection; a historical Watch receipt does not prove the phone still retains its copy. Never delete the only useful test evidence before consented export/read-back.

## Actual training contacts

After the end-to-end dry run passes, begin with one controlled intended contact per recording. Choose any listed type you can perform safely in normal practice; use Other / unclassified only when intentionally leaving the type unspecified, describing it in the owner note. Keep one intended type per short set. Other is independent of air-swing/non-stroke/uncertain contact labels and does not establish mixed-match recognition.

Label perceived clean contact, mishit or uncertain after the recording. Record contact feel separately from ball outcome. Do not infer shot times from attempt order; use a supported explicit interval/reference or leave unmatched. Optional owner-controlled video/partner reference may help but is not mandatory and is not automatically recorded. Repeat some labels later without showing the original answer; retain disagreements. Compare separate practice sessions before any personal signal conclusion. No paid coach, population study or automatic quality/technique claim is required or established.
