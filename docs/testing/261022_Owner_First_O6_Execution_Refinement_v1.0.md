## Recovery calculation version1
Use median of at least two admitted eligible samples. End-time membership is precisely (lower, upper]; independently require the entire original source interval to lie inside one eligible uninterrupted segment with matching practice/device/consent/clock scope. End-time membership does not require the entire interval to be inside the nominal statistical window. Preserve sample count and actual span. Zero-duration and adjacent-segment boundary cases must be deterministic and nonduplicating. Eligible kinds: baseline only observed pre-set baseline or prior recovery/rest before this set; end reference only active segments of this exact set; targets only recovery/rest associated with the stopped set and containing the complete target window uninterrupted. Paused, ending, interrupted, consent-excluded and clock-invalid segments are ineligible.

Baseline uses the30 seconds preceding set Start; end reference uses the final10 seconds before Stop. Recovery target+60 uses (Stop+50,Stop+70]; target+120 uses (Stop+110,Stop+130]. Each target stays pending until its full upper boundary is observed uninterrupted; stopping, pausing, next set or interruption before that boundary makes the standard value missing. Samples at+50/+54 with next set at+55 MUST NOT produce+60 recovery. A source interval crossing Pause/End/next-set boundary is ineligible even if its end falls inside the nominal window. Missing baseline/end makes dependent values missing. Compute signed end-reference minus later-window BPM, preserving negative drops. No interpolation, carry-forward, return-to-normal/fitness/accuracy claim, or history fallback.
