## Delivery of each test

Give the owner one observable action at a time, using the final app's actual labels. For every action, record expected result, actual result, evidence location and disposition before progressing. Preserve every failure. Do not repeatedly retry an unexplained failure or describe an unobserved result as passed. Keep hardware identifiers, raw recordings and Health data out of public GitHub evidence.

## First dry run — no ball

1. Open the iPhone's main practice setup through **Let’s Play**. Confirm the owner declaration and local motion/reference-label choices; make the separate optional heart-rate choice. Explain that an owner workout can affect system Health/Activity even though this app saves no workout summary. Successful HealthKit authorization is not proof that heart-rate samples will be readable.
2. Review the saved handedness and actual racket arm, then choose **Forehand** for this development set. Send/confirm the setup on the phone. Offline or pending status must remain visible until the matching Watch acknowledgement; preferences or delivery must never start capture.
3. Move and fasten the Watch on the actual playing arm. Check its system wrist/crown configuration. On Watch, make the fresh brief placement/fit confirmation required for this set. Detailed setup remains on iPhone. No start may occur from a stale confirmation or phone command.
4. Explicitly start locally on Watch and respond to the actual system permission prompts. Observe the state and both real motion streams. Record accepted counts, source timestamps, storage status and any missing-channel/failure message. A timer or changing UI alone is not sensor evidence.
5. Make a few comfortable forehand air swings while leaving screen controls alone, then stop the set. Confirm the actual motion source has stopped and data is saved or visibly interrupted. Any recovery observation must remain attached to this practice and its optional HR consent.
6. Let the between-set recovery window run without starting another set, if HR was selected. Record accessible samples and coverage. The +60-second and +120-second results require their complete windows through +70 and +130 seconds respectively. Missing/sparse data must stay missing; do not infer normal pulse, fitness or medical recovery. At +130 seconds the workout must pause pending explicit continuation.
7. On iPhone, select **Backhand** for the next set within the same practice. Confirm acknowledgement, repeat the short fresh Watch placement/fit check and start locally. Make a few comfortable backhand air swings, then stop. Verify the first set retains Forehand and the second retains Backhand, with different immutable recording IDs.
8. End the whole practice explicitly. Observe stopped motion/HR/workout resources and a finalized ended/interrupted state. The current candidate is bounded to120 active seconds per set,20 sets and30 elapsed minutes per practice; it is not full-match analysis.
9. Verify delivery on iPhone. Distinguish raw-only set receipt from verified complete owner-practice receipt. Compare the finalized set inventory, intended strokes, raw counts/digests, context, labels, HR or absence descriptor and lifecycle/coverage events. A queued transfer, OS transfer completion or raw receipt alone must not be shown as complete owner evidence.
10. Review the phone motion charts and available practice/HR/recovery results. Air swings must not become clean/mishit ball-contact labels, automatic shot counts or accuracy scores. Missing HR and interrupted coverage must remain explicit. The Watch is a logger with brief status; detailed interpretation belongs on iPhone.
11. Deliberately export the finalized whole practice after reviewing its contents. Use an owner-controlled private destination. Read it back through the production verification path and compare identities, inventory, component sizes/hashes, raw bytes, label revisions and HR/absence descriptor. Retain both source copies. Do not automatically upload health/raw data to Drive, GitHub or another service.

## Separate resilience observations

Run each as its own short practice after the first complete roundtrip. Record actual stream counts, gaps, lifecycle events and final status rather than assuming continuity.

| Scenario | Required observation |
| --- | --- |
| Wrist lowered / app no longer frontmost | Real samples and reported coverage reflect actual acquisition; no fabricated continuity. |
| iPhone unavailable during capture | Watch capture remains independent; later delivery verifies exactly the retained whole practice without duplicate sets. |
| Pause/resume and early next-set start | Pause/cutoff gaps are explicit; incomplete recovery windows remain missing; each new set needs fresh Watch confirmation. |
| Interruption or app relaunch | No silent restart; old authority is retired and retained partial data is honestly identified. |
| Optional HR absent or unreadable | A legitimate owner motion practice remains usable; no unrelated/history/device samples fill the gap. |
| End/HR-disable/withdrawal racing with work | New admission is blocked; old callbacks stay on the original context or are excluded; disconnected Watch acknowledgement remains pending. |
| Repeated transfer and receipt | Matching duplicates are idempotent; conflicts fail visibly; source retention is unchanged. |
| Capacity, time or resource failure | Capture closes or blocks visibly under the implemented limits; no silent eviction or stale readiness. |
| Battery/thermal observation | Record duration, foreground/background use, enabled channels and start/end charge; do not extrapolate one short set to full-match battery life. |

After privately retaining the useful dry-run evidence, test **Delete entire practice** cancellation and confirmation. Confirm all app-owned raw/context/labels/HR/derivatives/staging/cache/export-temporary copies for that practice are removed locally. Durable minimal guards must prevent replay/import resurrection. A paired request stays **Watch cleanup pending** until actual covered Watch cleanup is acknowledged. Independent exports and system Health records are outside app-local deletion. Never call the other device clean solely from a local success or historical transfer receipt.

## Owner contact collection after dry-run acceptance

Collect both forehand and backhand during normal practice in separate short, single-intent sets. Record practical perceived clean-contact/mishit/uncertain definitions before collection, and retain non-shot/air-swing intervals. Use an actual timing reference when available; order alone does not establish contact time. Record uncertainty rather than inventing alignment.

Label contact feel separately from ball outcome. Repeat selected labels later without displaying the original answer; retain disagreements. Keep separate practice sessions for development and unchanged-rule evaluation. Self labels are useful personal references and are not independent ground truth. No paid coach or large study is required for this personal feasibility phase. Automatic recognition, contact-quality prediction and general-player claims remain unproven until their own evaluation.
