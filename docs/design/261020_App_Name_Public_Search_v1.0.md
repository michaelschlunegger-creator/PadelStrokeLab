# Public app-name check — v1.0

20 October 2026. Owner requested renaming the app to **Padel Trainer**, first checking that name and alternatives including Padel Buddy and Padel Coach. This report is a public search, not a reservation or trademark clearance.

## Method and scope

Queried Apple's public software-search catalogue for US, UK, Switzerland, UAE and Germany, using the names below, software entity/media and up to 200 results per query. All 35 primary/alternative country queries succeeded. Also queried the joined variants **PadelTrainer** and **PadelForm** in all five storefronts; all 10 requests succeeded with no matching titles. Compared case, spacing and punctuation. Exact-phrase public web searches checked visible related brands and store listings. Country coverage and query success are search evidence, not a complete worldwide catalogue or proof that an unpublished/reserved name is free.

Private structured evidence is retained as `root/19-app-name-store-search.json`, `20-name-alternatives-store-search.json` and `21-name-joined-variants-search.json` under the existing GuidedSetup DerivedData evidence root. No App Store Connect account was modified; no name, domain or trademark was reserved.

## Recommendation and owner decision

Recommend **PadelForm**: compact, connected to stroke form and personal improvement, and usable for the later player community. This is a product/branding judgement, not a trademark opinion. **Padel Trainer** remains the owner's stated preference, but the related PadelTrainer.ai use warrants a deliberate choice before applying it.

Owner was asked to choose PadelForm or Padel Trainer despite that existing web use. Choice is pending. No public-facing strings, app display names, project identifiers, historical records or bundle identifiers have been changed by this research.

Apple confirms that app names are localized and may already be in use when creating a record. Public search cannot expose all reserved/unpublished names. Final Apple-name acceptance requires the appropriate App Store Connect record/localization operation; see [Apple: add a new app](https://developer.apple.com/help/app-store-connect/create-an-app-record/add-a-new-app/) and [app information/name rules](https://developer.apple.com/help/app-store-connect/reference/app-information/app-information/). Names must be 2–30 characters. Domain and trademark registration availability have not been established.
